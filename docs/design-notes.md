# 设计笔记 Design notes

> 注：笔记写于“信号肽”阶段，文中的“SP”泛指目标序列；通用 DNA 模式（可无同源臂、可关闭编码序列检查）见主 README。

> 中文详细笔记；项目概览见上级目录的 [README.md](../README.md)。

信号肽 DNA → 带同源臂的 3 条寡核苷酸（F / M / R）→ 独立验证 → 订购表。单文件网页 `index.html`，浏览器直接打开。

## 设计结构
- `F` = 上游臂 + SP 5′ 段（≤60 nt）；`M` = 中间有义链模板（≤60 nt，不带臂）；`R` = 下游臂 + SP 3′ 段的反向互补（≤60 nt）。
- F 3′ 端与 M 5′ 端序列相同，R 3′ 端与 M 3′ 端互补，F 与 R 之间可以直接重叠（短片段常见，对组装无害；M 仍须从 F 的 5′ 侧起、到 R 的 3′ 侧止）。
- PCR：只设一个退火温度 60 °C（诺唯赞 P516/P526 通用程序）。M 低浓度（约 0.02 µM），无模板 DNA。

## Tm 算法（2026-11-04 校准）
- 最初沿用单点突变工具的 Tm（SantaLucia 1998 + `16.6·log10[Na⁺]` 经验盐校正，50 mM、250 nM）。它比 SnapGene 低约 7 °C：用户给的 C01 设计，SnapGene 显示两个重叠区 59 °C，该算法给 51.7 / 52.5 °C。
- 现在改用 SantaLucia 1998 的熵项盐校正 `dS += 0.368·(N-1)·ln[Na⁺]`，50 mM Na⁺、引物 0.9 µM。参数是用 8 个 SnapGene 读数（用户提供，均为取整值）网格拟合出来的，8 个读数都落在读数区间 ±0.9 °C 内（`tests/test_design.py::test_tm_matches_snapgene_readings`）。这不是 SnapGene 公开的参数，只是经验拟合；超出这 8 个读数覆盖的序列范围时误差未知。
- P516 说明书的规则（正反向引物 Tm 均 >50 °C 时 60 °C 退火）用的是 Primer Premier 5 的 Tm，与 SnapGene 口径也不同；这一层差值未核实。
- 默认目标窗口 59–61 °C（SnapGene 口径），硬下限 55 °C。结果：9 条 SP 的重叠区 Tm 为 58.9–60.3 °C。
- F 与 R 允许直接重叠（用户自己的 C01 设计就是这样）；M 须从 F 的 5′ 侧起、到 R 的 3′ 侧止。

## 验证
`verify()` 只看最终的三条寡核苷酸：模拟 PCR 闭包（3′ 端 ≥12 nt 配对即延伸），断言能组装出 上游臂+SP+下游臂 及其互补链，且池中没有不属于目标产物的链；再检查 ATG、读码框、终止密码子、预期氨基酸。
`tests/test_design.py` 用 Python 另写一套闭包与 Tm 去核对，并做变异测试（改碱基、删碱基、F/R 互换、重叠断开、臂改错），确认验证器会拦下。

运行测试见 [README](../README.md#tests)。

## 没覆盖的
- 与载体联合的读码框检查（需要载体序列；下游臂 14 nt 不是 3 的倍数）。
- 引物在载体上的错配位点搜索（需要载体序列）。
- 湿实验：M 用量、循环数、60 °C 单一退火对 18–39 nt 重叠区是否足够，都是推断，没有实验。
- Tm 校准只用了 8 个 SnapGene 读数。
